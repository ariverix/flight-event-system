# ШАГ 7: АУТЕНТИФИКАЦИЯ И БЕЗОПАСНОСТЬ (JWT)

## Что сделать:

Реализация UC-09 (Управлять пользователями) и функции аутентификации.

### REST API:

| Метод | URL | Описание | Доступ |
|---|---|---|---|
| POST | /api/v1/auth/login | Вход, возвращает JWT-токен | Все |
| POST | /api/v1/auth/register | Регистрация нового пользователя | Только ADMIN |
| GET | /api/v1/auth/me | Информация о текущем пользователе | Авторизованные |
| GET | /api/v1/users | Список пользователей | Только ADMIN |
| PUT | /api/v1/users/{id}/toggle | Включить/выключить пользователя | Только ADMIN |

### Сервисы (модуль `user/`):

- `UserService` — регистрация, поиск по username, проверка пароля (BCrypt), список пользователей
- `JwtService` — генерация JWT (JJWT 0.12.x), валидация, извлечение username и роли. Время жизни токена: 24 часа. Секрет из application.yml (`app.jwt.secret`).

### SecurityConfig (корневой пакет):

```java
/**
 * Конфигурация безопасности.
 * JWT-аутентификация, stateless сессии, CORS для dev-сервера.
 * См. диплом: Глава 2, раздел «Безопасность»
 */
```

- `JwtAuthenticationFilter` — фильтр перед UsernamePasswordAuthenticationFilter. Извлекает JWT из заголовка `Authorization: Bearer <token>`. При валидном токене — устанавливает SecurityContext.
- CORS: разрешить `http://localhost:5173` (Vite dev server) и `http://localhost:3000`
- CSRF: отключить (JWT-based, stateless)
- Sessions: STATELESS

### Правила авторизации:

```java
.requestMatchers("/api/v1/auth/login").permitAll()
.requestMatchers("/api/v1/messages/**").permitAll()   // Внешние системы (UC-06)
.requestMatchers("/api/v1/flights/**").permitAll()    // Внешние системы (UC-06)
.requestMatchers("/api/v1/auth/register").hasRole("ADMIN")
.requestMatchers("/api/v1/users/**").hasRole("ADMIN") // UC-09
.requestMatchers("/api/v1/sequences/**").hasAnyRole("OPERATOR", "ADMIN")
.requestMatchers("/api/v1/executions/**").hasAnyRole("OPERATOR", "ADMIN")
.requestMatchers("/actuator/**").hasRole("ADMIN")
.requestMatchers("/swagger-ui/**", "/v3/api-docs/**").permitAll()
```

### DTO:
- `LoginRequest(username, password)`
- `LoginResponse(token, username, role, fullName)`
- `RegisterRequest(username, password, fullName, role)`
- `UserResponse(id, username, fullName, role, enabled, createdAt)`

### Контроллер:
- `AuthController` (adapter/in/) — логин, регистрация, me
- `UserController` (adapter/in/) — список пользователей, toggle

### AuditLog:
Записывать USER_LOGIN (успешный), USER_REGISTERED, USER_TOGGLED

## Критерий завершения:
Логин admin/admin работает, JWT выдаётся, защищённые эндпоинты требуют Bearer token, незащищённые (messages, flights) доступны без авторизации. Тесты на JWT генерацию/валидацию.
