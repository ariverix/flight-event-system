### JPA-сущности:

**Sequence (sequence/domain/):**
```java
@Entity @Table(name = "sequences")
public class Sequence {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(nullable = false, length = 100)
    private String name;
    
    @Column(length = 500)
    private String description;
    
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private SequenceStatus status;          // DRAFT, ACTIVE, INACTIVE
    
    @Column(name = "start_criteria", columnDefinition = "jsonb")
    private String startCriteriaJson;       // JSONB — критерии запуска
    
    @Column(name = "stop_criteria", columnDefinition = "jsonb")
    private String stopCriteriaJson;        // JSONB — критерии остановки
    
    @OneToMany(mappedBy = "sequence", cascade = CascadeType.ALL, orphanRemoval = true)
    @OrderBy("orderIndex ASC")
    private List<Step> steps = new ArrayList<>();
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
    private Long createdBy;
}
```

**Step (sequence/domain/):**
```java
@Entity @Table(name = "steps")
public class Step {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "sequence_id", nullable = false)
    private Sequence sequence;
    
    @Column(name = "order_index", nullable = false)
    private Integer orderIndex;             // Порядковый номер шага (1, 2, 3...)
    
    @Column(length = 100)
    private String name;
    
    @Enumerated(EnumType.STRING)
    @Column(name = "step_type", nullable = false)
    private StepType stepType;              // ACTION, EVALUATE, WAIT
    
    @Column(name = "config", columnDefinition = "jsonb")
    private String configJson;              // JSONB — конфигурация шага
    
    @Column(name = "timeout_seconds")
    private Integer timeoutSeconds;         // Таймаут для WAIT (null для ACTION/EVALUATE)
    
    // Правила перехода при SUCCESS (Result Decision Maker)
    @Enumerated(EnumType.STRING)
    @Column(name = "on_success_action", nullable = false)
    private TransitionAction onSuccessAction;   // CONTINUE, GOTO, END, ABORT
    
    @Column(name = "on_success_goto_step")
    private Integer onSuccessGotoStep;          // Номер шага для GOTO (null если не GOTO)
    
    @Column(name = "on_success_notify")
    private Boolean onSuccessNotify = false;    // Уведомить оператора при успехе
    
    // Правила перехода при FAILURE
    @Enumerated(EnumType.STRING)
    @Column(name = "on_failure_action", nullable = false)
    private TransitionAction onFailureAction;
    
    @Column(name = "on_failure_goto_step")
    private Integer onFailureGotoStep;
    
    @Column(name = "on_failure_notify")
    private Boolean onFailureNotify = false;
}
```

**ExecutionInstance (execution/domain/):**

> **ВАЖНО:** `sequenceId` хранится как Long БЕЗ FK (межмодульное разделение — execution модуль не ссылается на sequence модуль напрямую). Добавь индекс в Flyway-миграции.

```java
@Entity @Table(name = "execution_instances")
public class ExecutionInstance {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(name = "sequence_id", nullable = false)
    private Long sequenceId;                // БЕЗ FK (межмодульная граница)
    
    @Column(name = "aircraft_id", nullable = false)
    private String aircraftId;              // Привязка к ВС
    
    @Column(name = "flight_number")
    private String flightNumber;
    
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private ExecutionStatus status;         // RUNNING, WAITING, COMPLETED, ABORTED
    
    @Column(name = "current_step_index")
    private Integer currentStepIndex;
    
    @Column(name = "context", columnDefinition = "jsonb")
    private String contextJson;             // JSONB — контекст выполнения
    
    @Column(name = "wait_started_at")
    private LocalDateTime waitStartedAt;    // Когда начали ожидание (для fromThisPointOnly!)
    
    @Column(name = "wait_timeout_at")
    private LocalDateTime waitTimeoutAt;    // Когда таймаут истечёт
    
    @OneToMany(mappedBy = "executionInstance", cascade = CascadeType.ALL)
    @OrderBy("executedAt ASC")
    private List<StepExecution> stepHistory = new ArrayList<>();
    
    private LocalDateTime startedAt;
    private LocalDateTime completedAt;
}
```

**StepExecution (execution/domain/):**
```java
@Entity @Table(name = "step_executions")
public class StepExecution {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "execution_instance_id", nullable = false)
    private ExecutionInstance executionInstance;
    
    private Integer stepIndex;
    
    @Enumerated(EnumType.STRING)
    private StepType stepType;
    
    @Enumerated(EnumType.STRING)
    private StepResult result;              // SUCCESS, FAILURE
    
    @Enumerated(EnumType.STRING)
    private TransitionAction transitionAction;  // Какое решение было принято
    
    private Integer transitionTarget;       // Номер шага для GOTO (null для остальных)
    
    @Column(columnDefinition = "jsonb")
    private String detailsJson;             // JSONB — детали выполнения
    
    private LocalDateTime executedAt;
}
```

### Примеры значений JSONB-полей:

**configJson для ACTION:**
```json
{"actionType": "SEND_UPLINK", "templateName": "WEATHER_REPORT", "parameters": {"airport": "EGLL"}}
{"actionType": "RAISE_CONDITION", "conditionName": "NO_POSITION_15MIN", "alertLevel": "MEDIUM"}
{"actionType": "CLOSE_CONDITION", "conditionName": "NO_POSITION_15MIN"}
{"actionType": "SEND_GROUND", "recipients": ["OPS_CENTER"], "templateName": "ALERT", "parameters": {"reason": "NO_POSITION"}}
{"actionType": "WAIT_TIME", "durationSeconds": 600}
```

**configJson для EVALUATE IF / WAIT FOR:**
```json
{"criterionType": "MESSAGE_RECEIVED", "messageType": "DOWNLINK", "templateName": "POSITION_REPORT"}
{"criterionType": "MESSAGE_RECEIVED", "messageType": "DOWNLINK", "templateName": "POSITION_REPORT", "fromThisPointOnly": true}
{"criterionType": "FLIGHT_STAGE", "operator": "EQUALS", "stage": "OFF"}
{"criterionType": "FLIGHT_STAGE", "operator": "GREATER_EQUAL", "stage": "ON"}
{"criterionType": "POSITION_REPORTED", "reported": true, "withinMinutes": 15}
{"criterionType": "POSITION_REPORTED", "reported": false, "withinMinutes": 15}
{"criterionType": "TIME_COMPARISON", "reference": "OFF", "operator": "IS_AFTER", "offsetMinutes": 10}
{"criterionType": "TIME_COMPARISON", "reference": "ETD", "operator": "IS_BEFORE", "offsetMinutes": -5}
{"criterionType": "CONDITION_ACTIVE", "conditionName": "NO_POSITION_15MIN"}
{"criterionType": "COMPOUND", "operator": "AND", "criteria": [
    {"criterionType": "FLIGHT_STAGE", "operator": "EQUALS", "stage": "OFF"},
    {"criterionType": "MESSAGE_RECEIVED", "messageType": "DOWNLINK", "templateName": "POSITION_REPORT"}
]}
```

> **КРИТИЧЕСКИ ВАЖНО — fromThisPointOnly:** В configJson для WAIT-шагов с criterionType MESSAGE_RECEIVED может быть поле `"fromThisPointOnly": true`. Это означает: учитывать ТОЛЬКО сообщения, полученные ПОСЛЕ `waitStartedAt` экземпляра. Это ключевое отличие WAIT FOR от EVALUATE IF в эталонной системе Sequencer (ASP Guide, раздел 5.13). Этот флаг доступен ТОЛЬКО для WAIT-шагов, НЕ для EVALUATE.

**startCriteriaJson:**
```json
{"criterionType": "FLIGHT_STAGE", "operator": "EQUALS", "stage": "OFF"}
```
```json
null
```
> Пустой (null) start criteria = последовательность запускается в начале каждого нового рейса.

**stopCriteriaJson:**
```json
{"criterionType": "FLIGHT_STAGE", "operator": "GREATER_EQUAL", "stage": "ON"}
```
```json
null
```
> Пустой (null) stop criteria = последовательность завершается только через END или ABORT в шаге.
