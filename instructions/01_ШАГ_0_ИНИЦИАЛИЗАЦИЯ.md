**Backend (Maven pom.xml):**
- Parent: `spring-boot-starter-parent` 3.5.0
- Java: 21
- Зависимости: spring-boot-starter-web, spring-boot-starter-data-jpa, spring-boot-starter-security, spring-boot-starter-validation, spring-boot-starter-actuator, spring-modulith-starter-core, spring-modulith-starter-jpa, easy-rules-core 4.1.0, easy-rules-support 4.1.0, postgresql (runtime), flyway-core, flyway-database-postgresql, lombok, jjwt-api/impl/jackson 0.12.x, springdoc-openapi-starter-webmvc-ui 2.8.x, spring-boot-starter-test, spring-modulith-starter-test, testcontainers postgresql

**application.yml:**
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/eca_db
    username: eca_user
    password: eca_password
  jpa:
    hibernate:
      ddl-auto: validate  # Flyway управляет схемой, JPA только валидирует
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
  flyway:
    enabled: true
    locations: classpath:db/migration
  modulith:
    events:
      jdbc:
        schema-initialization:
          enabled: true  # Для Transactional Outbox

server:
  port: 8080

management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics

logging:
  level:
    ru.protectinfotrans.eca: DEBUG

app:
  jwt:
    secret: eca-jwt-secret-key-for-development-minimum-256-bits-long
    expiration-ms: 86400000  # 24 часа
```

**Docker Compose (2 сервиса):**
- `postgres`: image postgres:16-alpine, порт 5432, healthcheck с pg_isready, volume для данных, env: POSTGRES_DB=eca_db, POSTGRES_USER=eca_user, POSTGRES_PASSWORD=eca_password
- `app`: сборка из `./backend`, порт 8080, зависит от postgres (condition: service_healthy)

**Frontend:**
- Инициализировать Vite + React + TypeScript проект
- Установить: react-router-dom, axios, antd, @ant-design/icons, @xyflow/react, dagre

## Критерий завершения:
- `mvn clean compile` проходит без ошибок
- `docker-compose up postgres` запускает PostgreSQL
- Spring Boot стартует и подключается к БД
- Frontend собирается через `npm run build`
