# ШАГ 1: СТРУКТУРА МОДУЛЕЙ (Spring Modulith)

## Что сделать:

**Создай пакетную структуру из 5 модулей** внутри `ru.protectinfotrans.eca/`:

Каждый модуль — отдельный пакет верхнего уровня с `package-info.java` и аннотацией `@ApplicationModule`:

1. **`sequence/`** — модуль Sequence Manager
   - Подпакеты: `domain/`, `port/in/`, `port/out/`, `application/`, `adapter/in/`, `adapter/out/`, `dto/`, `event/`
   
2. **`execution/`** — модуль Execution Engine
   - Подпакеты: `domain/`, `port/in/`, `port/out/`, `application/`, `adapter/in/`, `adapter/out/`, `rules/`, `dto/`, `event/`

3. **`eventprocessor/`** — модуль Event Processor
   - Подпакеты: `domain/`, `port/in/`, `port/out/`, `application/`, `adapter/in/`, `adapter/out/`, `dto/`, `event/`

4. **`integration/`** — модуль Integration Adapter
   - Подпакеты: `port/in/`, `port/out/`, `application/`, `adapter/out/`, `event/`

5. **`user/`** — модуль User Management
   - Подпакеты: `domain/`, `port/in/`, `application/`, `adapter/in/`, `dto/`

6. **Общие классы (НЕ отдельный модуль):**

> **ВАЖНО:** По умолчанию Spring Modulith считает каждый подпакет корневого пакета отдельным модулем. Общие классы (FlightStage, MessageType, исключения, конфигурация) размещай в КОРНЕВОМ пакете `ru.protectinfotrans.eca/` — Spring Modulith автоматически делает корневой пакет видимым для всех модулей.

**Общие enum-классы в корневом пакете:**
- `FlightStage`: INIT, OUT, OFF, ON, IN (стадии OOOI из раздела 1.1.4 диплома; НЕ использовать NONE — в эталонной системе начальная стадия называется Init)
- `MessageType`: DOWNLINK, UPLINK, GROUND (типы сообщений ACARS из раздела 1.1.2 диплома)

**Общие классы в корневом пакете:**
- `GlobalExceptionHandler` (@RestControllerAdvice) — обработка ошибок для всех модулей
- `SecurityConfig` — конфигурация Spring Security (реализуется в Шаге 7, пока заглушка с permitAll)

**Enum-классы в sequence/domain/:**
- `StepType`: ACTION, EVALUATE, WAIT
- `ActionType`: SEND_UPLINK, SEND_GROUND, RAISE_CONDITION, CLOSE_CONDITION, WAIT_TIME
- `CriterionType`: MESSAGE_RECEIVED, FLIGHT_STAGE, POSITION_REPORTED, TIME_COMPARISON, CONDITION_ACTIVE, COMPOUND
- `TransitionAction`: CONTINUE, GOTO, END, ABORT
- `SequenceStatus`: DRAFT, ACTIVE, INACTIVE
- `ComparisonOperator`: EQUALS, NOT_EQUAL, GREATER, LESS, GREATER_EQUAL, LESS_EQUAL

**Enum-классы в execution/domain/:**
- `ExecutionStatus`: RUNNING, WAITING, COMPLETED, ABORTED
- `StepResult`: SUCCESS, FAILURE

**Enum-классы в user/domain/:**
- `Role`: OPERATOR, ADMIN

Пакетная структура создана, все package-info.java на месте, архитектурный тест проходит, приложение компилируется.
