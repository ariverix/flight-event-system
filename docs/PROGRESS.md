### CI-регрессия (2026-06-24): красный пайплайн — починено
- **Корень обеих красных джоб (Backend + Security scan): `mvnw` хранился в git с
  CRLF-окончаниями.** На Linux-раннере `bash mvnw` падал сразу: `mvnw: line 37:
  syntax error near unexpected token $'in\r'` → exit 2. OWASP-скан при этом ни разу
  не выполнялся (CVE не находились — степ умирал до запуска). Гипотезы «нет postgres»
  и «уязвимые зависимости» не подтвердились по логам CI (postgres стартовал, отчёт
  dependency-check не генерировался вовсе).
- **Фикс:** нормализация `mvnw` → LF + `.gitattributes` (`mvnw`/`*.sh` = LF,
  `*.cmd`/`*.bat` = CRLF), чтобы не регрессировало. Превентивно: Spring Boot
  3.5.0 → 3.5.15 (свежие патчи транзитива; локально `mvn verify` зелёный, 796 тестов).
