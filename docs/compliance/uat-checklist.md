# Приёмочный чек-лист (UAT) — ECA System v1.0

**Версия:** 1.0  
**Дата:** 2026-06-28  
**Статус:** Актуально (P8-3)  
**Ответственный:** compliance-agent + заказчик (ФГУП «ЗащитаИнфоТранс»)  
**Основание:** матрица паритета `docs/compliance/parity-matrix.md`  

Чек-лист является основой для пользовательского приёмочного тестирования. Каждый пункт должен быть отмечен исполнителем с указанием даты проверки и результата. Тест считается пройденным, если статус «ПРОШЁЛ». Критерии приёмки в конце документа.

**Стенд:** Docker Compose (`docker-compose up --build`), http://localhost:8080  
**Учётные данные по умолчанию:** admin / admin  
**Демо-борт:** VP-BQR, рейс SU1234
